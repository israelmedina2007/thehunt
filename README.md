# The Hunt Burgers and Fries

Sitio web estático (un solo archivo, sin build) para The Hunt Burgers and Fries, La Paz, B.C.S.

## Publicar
- **Hostinger:** sube `index.html` a `public_html`.
- **GitHub Pages:** Settings > Pages > Deploy from a branch > `main` / root.
